# Honey Shop

Monorepo for the Honey Shop e-commerce platform.

## Structure

```text
honey-shop/
├── frontend/     # React + Vite storefront & admin panel
├── backend/      # API (to be built)
└── .trackers/    # Engineering state (Engineer Mode)
```

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

The storefront will be available at `http://localhost:5173`.

### Backend

Coming soon. Scaffold is ready in the `backend/` directory.

## Deployment

Frontend is intended for **Vercel**.
